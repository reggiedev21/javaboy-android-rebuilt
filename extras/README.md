# Fonctionnalités optionnelles mises de côté

- `GameBoyPrinter.java` : émulation de l'imprimante Game Boy (fenêtre AWT).
- `TCPGameLink.java` : câble link via TCP.

Elles ne sont pas compilées. Elles pourront être réintégrées derrière
l'interface `GameLink` du cœur une fois le portage terminé (bonus phase 5).
